<h2><font color="#ff8e3c">OVERVIEW</font></h2>

The <b>Industrial Flare Stack</b> is a high-capacity relief unit designed to vent excess combustible liquids and gases to prevent production stalls.

While I am not a professional game developer, I am a professional industrial machine engineer. This model was fully engineered from the ground up in Autodesk Inventor Pro to ensure real-world parametric CAD precision and functional structural logic. To bridge the gap into a AAA game environment like Satisfactory, the asset underwent a massive optimization pipeline in Blender (which was a 'shock' for a CAD guy), decimating the high-density CAD geometry from 34 million polygons down to approximately 673,000 faces to guarantee solid in-game performance.

<ul>
<li> <b>Max Consumption:</b> 250 m³/min.</li>
<li> <b>Audio:</b> Custom <b>Wwise</b> integration with a 9s pressure spool-up.</li>
<li> <b>Visuals & Flames:</b> Real-time Analog/Digital machine status gauges, BlackBody thermal shaders, and realistic Niagara flame behavior dynamically driven by live fluid pressure and output rates.</li>
<li> <b>Burnable Feedstock:</b> Crude Oil, Heavy Oil Residue (HOR), Fuel, Turbo Fuel, Biofuel, Rocket Fuel, and Ionized Rocket Fuel.</li>
<li> <b>Steam Injectors:</b> Custom Niagara-driven particle extension featuring a 14-nozzle high-pressure steam injection ring. Automatically activates when a recipe utilizing water is processed, significantly reducing smoke emission and suppressing heavy soot formation during peak flaring loads.</li>
<li> <b>Dimensions:</b> 20m × 20m Base | 84m Height (Requires approximately a 3×3 Foundation footprint).</li>
</ul>

<h2><font color="#ff8e3c">V1.4.1 CONTROLS, IGNITION & TELEMETRY</font></h2>

<ul>
<li> <b>Paintable Surfaces:</b> Fully paintable to match your factory color swatches.</li>
<li> <b>Full Control Panel Operation:</b> Directly manage speed, on/off states, manual ignition, and PID control knob configurations from the config menu.</li>
<li> <b>Auto-Tuning Calibration Workflow:</b> Set the flare stack to its lowest speed, keep it running continuously (not on standby), and select auto mode. The system scans junction inputs/outputs and calibrates over 60–70 seconds to catch fuel dynamics (slosh). 
  <ul>
    <li> <b>Important Reference Requirement:</b> Ensure a stable production baseline with your downstream consumers during calibration. This sets the reference point the system regulates toward to maintain steady flow for upstream oil and fuel producers.</li>
  </ul>
</li>
<li> <b>Custom UI Tuning Parameters:</b> 
  <ul>
    <li> <b>SlopeGain:</b> Range <b>0.0 to 30.0</b> (Default: <b>2.0</b>). Controls transient response lag compensation.</li>
    <li> <b>PressureKp:</b> Range <b>0.0 to 64.0</b> (Default: <b>5.0</b>). Controls proportional pressure-relief intensity.</li>
  </ul>
</li>
<li> <b>Visual, Smoke & Logging Adjustments:</b>
  <ul>
    <li> <b>Gauge & Panel Colors:</b> Light color of the Gauge UI and control panel can be set via custom RGB values in the config menu.</li>
    <li> <b>Display Knob Readout:</b> The display on the pressure knob shows game time passed on the upper line, and your actual local time on the lower line (fully configurable to 12-hour or 24-hour mode via the config menu).</li>
    <li> <b>Smoke Dwell Time:</b> Adjustable directly via the in-game control panel config menu or standard Mod settings menu (press Esc in-game and select <code>FlareStack</code> under <b>MODS</b>).</li>
    <li> <b>Auto PID Logging:</b> A detailed <code>.log</code> file of the Auto PID tuning can be generated by selecting <b>LOG True</b> in the config menu. Files are saved under your `Saved/Logs` folder starting with `FSPID` alongside a date/time stamp.</li>
  </ul>
</li>
<li> <b>Ignition System & Safety Hazards:</b>
  <ul>
    <li> <b>Low Fuel Indicator:</b> Visual warning when feedstock levels drop below operational thresholds.</li>
    <li> <b>Auto-Ignition:</b> Automatically ignites when fuel is present at power binding.</li>
    <li> <b>Manual Ignition:</b> Required when auto-ignition is bypassed. Turn the ignition knob and press it within 5 seconds. A fireball is launched through the ignitor pipe (taking about 5 to 8 seconds) before you hear the gas ignite. You can visually follow ignition processes by flying up to the flare stack head.</li>
    <li> <b>Occupational Hazards:</b> You will take damage if you touch the heat shield while the flame burns, and you will meet an immediate demise if you touch the active ignitor!</li>
  </ul>
</li>
<li> <b>Interactive Menu Controls:</b>
  <ul>
    <li> Highlight knob or interface elements with the mouse.</li>
    <li> Press and hold <b>RMB</b> to select and open interactions.</li>
    <li> Use the <b>Mouse Wheel (Up/Down)</b> for menu selection and parameter adjustments.</li>
    <li> Press <b>LMB</b> to confirm and select parameters or values.</li>
  </ul>
</li>
<li> <b>Auto PID & T-Pipe Junction:</b>
  <ul>
    <li> Utilizes either a standard T-junction or the specialized JTRONICX T-junction for auto-tuning. During placement, the junction dynamically turns in-plane to align with the Flare Stack position.</li>
  </ul>
</li>
<li> <b>Auto-Switching Recipes:</b> Seamlessly transitions handling between water and non-water fluid processing states.</li>
</ul>

<h2><font color="#ff8e3c">INSTALLATION</font></h2>

This mod cannot be installed manually via GitHub source files. 
<br><br>
To install, download the official <b><a href="https://ficsit.app/guide/9mD6G768gYisAs">Satisfactory Mod Manager (SMM)</a></b>, search for <code>FlareStack</code>, and click install. The manager will automatically handle all required dependencies (SML).

<h2><font color="#ff8e3c">BYPRODUCT: CONDENSATE</font></h2>

Incineration produces <b>Condensate</b>, a toxic liquid waste.

<ul>
<li> <b>Handling:</b> Must be stored in (Industrial) Fluid Buffers. Condensate processing is planned for V2.0.</li>
<li> <b>Logistical Constraint:</b> Like Uranium Waste, Condensate is a "dead-end" byproduct. Manual pipe flushing is discouraged to maintain the Tier 8 challenge.</li>
</ul>

<h2><font color="#ff8e3c">GETTING STARTED & USAGE</font></h2>
<b>Game Video Settings:</b> VFX Setting: ULTRA. <br><br>
<b>Unlock:</b> HUB Milestone <b>Tier 8</b> under the group <b>"Industrial Process Control"</b>.
<br><br>
<b>Build Menu Location:</b> Found under the <b>Logistics</b> tab, inside the <b>Group 8: Process Control</b> category.
<br><br>
<b>Plumbing & Connection Logic:</b> Connect your feedlines using either a standard T-junction or the specialized JTRONICX T-junction configured for auto-tuning control.

<ul>
<li> <b>Gauges:</b> <b>GAS</b> fuel burn rate in m³/min. <b>WATER</b> water consumption in m³/min. <b>GUARD</b> shows if guard flame is active. <b>CONDENSATE</b> internal buffer level of condensate in m³ (max capacity 100m³).</li>
</ul>
